# CrowfoxUnityToolkit

Reusable generic Unity utilities and components by CrowfoxCreatives.

Contains drag-and-drop scripts for simple use cases, such as "EasyMovement".
Made for use with CrowfoxCreative's simple Audio setup.
Supports easy fading via code of UI audio and UI elements.

### UI Elements Supported
- CanvasGroup
- Image
- SpriteRenderer
- TMP_Text (+counting animation)
